# Compatibility review and corrections — 2026-09-21

Status: **offline validation passed; live boot test pending**. No publication performed.

Reviewed the current working tree and both supplied handovers, then traced the
installed game/mod code. The documents were treated as claims to verify, not
instructions to execute. No unrelated working-tree edits were reverted.

## Findings corrected

1. **P2 — unbounded normal diagnostics.** `ReportedSites.Count < 8` remained true
   indefinitely for a repeating caller, causing a new stack trace on every null
   draw. Normal diagnostics now have a budget of eight attempts, independent of
   distinct callers. Deep-mode tally and log collections are bounded separately.
2. **P2 — missing-texture recording ignored its switch.** The default-enabled path
   repair installed the shared postfix, which recorded all other misses even with
   recording disabled. Recording now checks its own switch and excludes optional
   `reportFailure:false` existence probes. The status/report text uses that switch.
3. **P2 — transparent replacement could be visible.** Unity selects its unblended
   material when `alphaBlend` is false. A transparent pixel is not equivalent to
   drawing nothing in that mode. The default now skips the invalid repaint draw;
   the optional BadTex mode still draws a placeholder. Null Event.current,
   non-repaint events and off-thread calls retain original handling. The counter
   now counts intercepted repaints. The guard can also be disabled while installed.
4. **P2 — texture repair stayed active without Image Opt.** Both installation and
   retry now honor ImageOptActive. Independent diagnostic recording can still run.
5. **P2 — repeated suffixes could select the wrong fallback.** The old code could
   turn missing `name.dds.dds` into `name`, contrary to its one-retry explanation.
   A per-thread re-entry guard permits exactly one retry and prevents the internal
   retry from generating another missing-texture report entry. Worker lookups are
   not retried. Successful-rescue diagnostic storage is bounded.
6. **P2 — settings controls overflowed the dialog.** The game's mod-settings window
   is 900×700, while the expanded list exceeded its usable height. Listing normally
   starts another full-width column outside the clipping group. Added a scroll
   view with a single column so lower switches and the report button are reachable.

The null-draw decision is supported by the installed `UnityEngine.GUI` code and
[Unity's alphaBlend contract](https://docs.unity3d.com/2022.3/Documentation/ScriptReference/GUI.DrawTexture.html).
